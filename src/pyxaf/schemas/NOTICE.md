# Bundled XML schemas

These files are redistributed unchanged (CRLF line endings kept) for XSD validation
(`pyxaf[xsd]`) and as the source of pyxaf's generated field catalogues.

| File | Version | Publisher / source |
|---|---|---|
| `XmlAuditfileFinancieel4.0.xsd` | XAF 4.0 (package 4.0.3, 2025) | Belastingdienst, Ontwikkelaarsportaal (ODB): https://odb.belastingdienst.nl/wp-content/uploads/2025/04/XMLAuditfile-Financieel-XAF-v-4.0.3.zip (byte-identical to the XSD in that package) |
| `XmlAuditfileFinancieel3.2.1.xsd` | XAF 3.2.1 (package "XAF-3.2.2", 2024) | Belastingdienst; archived at softwarepakketten.nl |
| `XmlAuditfileFinancieel3.2.xsd` | XAF 3.2 (2014, re-published 2017) | XML Platform / auditfiles.nl (SRA, ABZ, Belastingdienst, GBNED); widely redistributed |
| `clair2-auditfile.xsd` | CLAIR2.00.00 (2003) | SRA (Harold Kinds), published by GBNED: http://www.gbned.nl/downloads/auditfile/auditfile.xsd (via the Internet Archive) |

The schemas remain the work of their publishers (the 4.0 documentation is marked "© XML
Platform"). None of the files states a licence: the ODB's public-domain statement covers the text
of its website, not necessarily these downloads. pyxaf redistributes them unchanged because they
are the published, freely downloadable definition of an open exchange standard that software must
implement. pyxaf is not affiliated with the publishers; a publisher who objects can open an issue
and the file will be removed.
