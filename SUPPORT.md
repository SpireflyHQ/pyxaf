# Getting help

- **Documentation:** <https://spireflyhq.github.io/pyxaf/>. The pages on
  [reading](https://spireflyhq.github.io/pyxaf/guide/reading/),
  [validation](https://spireflyhq.github.io/pyxaf/guide/validation/) and the
  [finding codes](https://spireflyhq.github.io/pyxaf/reference/codes/) answer most questions.
- **Bugs, file-compatibility problems and feature requests:** search the
  [issues](https://github.com/SpireflyHQ/pyxaf/issues) first, then open one with the matching form.
- **Security problems:** report them privately as described in [SECURITY.md](SECURITY.md), never
  in a public issue.

When you ask for help, include the pyxaf and Python versions, the output of `pyxaf detect FILE`,
the software that exported the file, and the finding codes. **Never attach a real auditfile**: it
contains personal and confidential financial data. A small hand-made snippet that shows the
problem is enough; [CONTRIBUTING.md](CONTRIBUTING.md#contributing-anonymised-samples) explains how
to make one.

pyxaf is maintained by volunteers. It is not affiliated with the Belastingdienst; questions about
whether the Belastingdienst accepts a file belong with the Belastingdienst.
