# Sample auditfiles

Synthetic XAF 4.0 files for trying pyxaf. They contain made-up data only.

| File | Contents |
|---|---|
| `2024.xaf` | a small, valid ledger for the fictional "Voorbeeld & Zonen B.V.": 11 accounts, 12 transactions, an opening balance |
| `2024-broken.xaf` | the same file with one mistyped amount (`3621.16` instead of `3612.16`), so validation reports two errors |

Download them without cloning the repository:

```bash
curl -L -O https://raw.githubusercontent.com/SpireflyHQ/pyxaf/main/examples/2024.xaf \
        -O https://raw.githubusercontent.com/SpireflyHQ/pyxaf/main/examples/2024-broken.xaf
```

The files are generated by `scripts/gen_examples.py` from the test-suite generator; do not edit
them by hand.
